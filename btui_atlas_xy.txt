BTUI TEXTURE ATLAS - COORDINATE REFERENCE
==========================================
Source file : custom/Assets/Textures/btui_texture_atlas.tga
Registered as: <Texture><Name>btui_atlas_tex</Name></Texture>  (see assets.xml)
Atlas size   : 512 x 512, RGBA 32-bit, RLE-compressed TGA, bottom-left origin
Coordinate system: X,Y pixel offsets measured from the atlas TOP-LEFT corner
                   (0,0 = top-left pixel), same convention DAoC's own
                   FullResizeImageTemplate/ButtonTemplate X/Y fields use.

How to read an entry below:
  - "Sprite bounds" = full extent of the artwork in the atlas, border included.
  - "Slice" values = TopHeight/BottomHeight/LeftWidth/RightWidth as used in a
    FullResizeImageTemplate. Each 3x3 sample's source X,Y = top-left pixel of
    that cell; sample width/height is implied by the LeftWidth/MiddleWidth/
    RightWidth (X-axis) and TopHeight/MiddleHeight/BottomHeight (Y-axis)
    values, exactly like the existing hybrid_panel_bg / btui_panel_bg
    templates in uistyles.xml / btui_styles.xml.
